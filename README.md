# Greater Victoria open map (demo)

A small web map of Greater Victoria, built by Claude, an AI model, for Darren Zal. It is a demo of an open, self-hostable alternative to embedding Google Maps for local groups in Greater Victoria. It shows watersheds, creeks (with animated flow direction), parks, ecosystem zones, terrain shading and a 3D terrain view (both on when the page opens) from open data, plus an optional layer for events and places. Optional layers add ecoregions, industry and waste sites, and live data from outside services (precipitation radar, weather alerts, air quality, current conditions, river gauges, earthquakes and life observations). It is a demo. It is not an official map of any group.

Status: published at https://darrenzal.github.io/greater-victoria-map/ (code in https://github.com/DarrenZal/greater-victoria-map). Built on 2026-10-21. Data retrieved 2026-10-21.

Repository name `greater-victoria-map`. The code is under the MIT licence, see [LICENSE](LICENSE) (Darren Zal, 2026). The MIT licence covers the code only. Each data layer keeps its own licence, recorded per layer in [data/SOURCES.md](data/SOURCES.md), and the MIT licence does not relicense any of it. The vendored MapLibre library keeps its own BSD-3-Clause licence in [vendor/MAPLIBRE-LICENSE.txt](vendor/MAPLIBRE-LICENSE.txt), which must stay with it.

## Run it locally

It is plain static files with no build step. From this folder:

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000/. Opening `index.html` straight from disk will not work, because browsers block module scripts and data requests on `file://` pages.

The page needs internet for the street basemap (tiles.openfreemap.org), for the elevation tiles (s3.amazonaws.com) behind Terrain shading and 3D terrain, which are on by default, and for each live layer (api.weather.gc.ca, geo.weather.gc.ca, earthquake.usgs.gov, api.gbif.org) once its box is ticked. If the basemap cannot be reached, the page shows the data layers on a plain background and adds a sentence to the banner. If a live service cannot be reached, its layer shows a plain failure line.

## What is on the map

Default on: the example place, creeks, lakes and wetlands (with Flow, below), parks and green spaces, terrain shading, 3D terrain, municipal boundaries. Default off: watersheds, ecosystem zones, ecoregions, industry and waste sites, and the seven live layers. Clicking a feature opens a popup with its name, type and source. Popups are built from plain text only, and only https links are clickable.

**Flow.** A sub-toggle under "Creeks, lakes and wetlands", on by default. Pale dashes march downstream along the creek lines from zoom 9 up, so a visitor can see which way Bowker Creek, the Colquitz River or Craigflower Creek drain. It shows drainage direction from provincial lines, not discharge or current. Reaches the Province maps as main flow in a natural channel, and reaches it maps as canals, get dashes. Pipes (subsurface flow) and connection lines do not, and the panel and credits say so. Canals were added on 2026-10-21: Bowker Creek now shows about 1,420 m of its roughly 2,110 m mapped length (about 480 m of natural channel and 940 m of canal), where it showed about 480 m before, and the other 680 m, mapped as subsurface flow, stays undashed. Under a system setting of reduced motion the layer is hidden altogether, the box is off and disabled, and the page follows the setting if it changes. The animation loop runs only while the dashes can be seen: the Flow and creeks boxes are on, this tab is in front and the map is zoomed to 9 or more. How the direction was found and checked is in [data/SOURCES.md](data/SOURCES.md).

**Terrain shading.** A hillshade drawn in the browser from AWS Terrain Tiles. On by default (since 2026-10-21, at Darren's request). Credits and the on-map attribution name the sources while it is on. With both terrain boxes unticked, no elevation tile is requested.

**3D terrain.** On by default (since 2026-10-21, at Darren's request): the map opens flat and tilts into relief once it has loaded, with no animation when the device asks for reduced motion. The box lifts the map into relief with MapLibre's terrain support, from the same AWS Terrain Tiles (a second source on the same tile address, because MapLibre warns that one source shared with the hillshade lowers the quality of both). The exaggeration is 2 (`TERRAIN_EXAGGERATION` in [js/app.js](js/app.js), 1 is true height). The map tilts to 60 degrees (`TERRAIN_PITCH`), drag-rotate, two-finger tilt and the compass are switched on, and a sky and fog are added. Unticking it removes the terrain and puts the pitch and bearing back to 0. While it is off, the map is flat and north-up and rotation is locked. The Terrain shading box stays independent of it. The relief has no lighting of its own, so the note under the box says Terrain shading gives the hills their light and shade. The parks, creeks, watersheds and the other flat layers are draped over the relief by MapLibre, and the check queries them with 3D on. The Flow dashes step at half the rate while 3D terrain is on, because each step redraws the draped creeks. Performance was not measured on a phone, see "Not tested yet" below.

**Ecoregions.** Off by default. The RESOLVE Ecoregions 2017 polygon for the area, loaded from this site on the first tick. The whole demo box falls in one ecoregion, Puget lowland forests, and the shape is a coarse copy, so the layer is a label for the region more than a map. See [data/SOURCES.md](data/SOURCES.md).

**Industry and waste sites.** Off by default. Eighteen sites in the box: 11 landfills and waste sites, 6 wastewater plants and pump stations and one power plant. Only records from sources whose licences were read as open are used. A dot with no figures is a location, not an empty site, and every figure says whether it was reported, is a capacity or is modelled.

**Live data.** Seven layers, grouped under "Live data" in the panel, off by default. Nothing is requested from an outside service until its box is ticked, and the panel says so. Each shows a plain status line, and a plain failure line if its request fails (the alerts line also says that the map is then not showing whether any alert is in effect). Each is loaded straight from the visitor's browser, so there is no key and no server of ours in between.

## Left out on purpose

None of these is in the demo, and none is linked.

- **Native Land territories, languages and treaties.** Its Data Sovereignty Treaty (https://api-docs.native-land.ca/data-sovereignty-treaty) lists "Store or distribute API data without explicit permission from Native Land Digital." as prohibited, so a copy of the polygons in this repository is out. Every API request needs a key tied to one person's agreement, and a static page cannot keep a key secret. Native Land Digital's own pages disagree (one says the data can be treated as CC0, the Treaty and FAQ say otherwise), so the stricter text governs. It needs Native Land Digital's written permission first. See open item A2.
- **RUSH rain garden map data and any link to RUSH.** Excluded until RUSH agrees.
- **HydroSHEDS HydroBASINS and HydroRIVERS.** The rights review is not recorded as cleared. The rivers file is 73 MB and 500 m resolution. The Freshwater Atlas replaces both.
- **Records, graph and people from the [Salish Sea Atlas](https://salishsee.life) project, and Indigenous place names.** Publishing Indigenous place names needs the Nations' permission, which has not been sought. The Atlas's industry and waste snapshot, ecoregion tiles and its live-layer endpoints were used as sources of data and methods, not its code.
- **Industry and waste sites from sources with unclear or share-alike licences.** The Atlas snapshot has 995 sites in the Salish Sea. Of the 29 in the demo box, 18 are shown. Dropped: 10 modelled river-plastic outfalls (points with no name, from a model, not sites), one wastewater plant named for a First Nation (this demo shows no First Nations content and no Nation has been asked, so the name is left out until someone decides), and every record from Climate TRACE (its terms list external datasets with other terms), IMF PortWatch (IMF terms) and Maus et al. mining footprints (CC BY-SA). Where a site has an open record and a Climate TRACE record, only the open record is used.
- **A Natural Resources Canada earthquake feed.** Looked for on 2026-10-21 and not found in a form a browser can read: the Earthquakes Canada site answered HTML with no Access-Control-Allow-Origin header, and no JSON or GeoJSON address was found. The U.S. Geological Survey catalogue is the only earthquake source.
- **Indian Reserves, Sensitive Ecosystems Inventory, Water Licensing Watersheds.** Held for a later decision. Water Licensing Watersheds is "Access Only", not open data.

## Adding pins

Edit [data/pins.geojson](data/pins.geojson) on GitHub or in a pull request. A pin appears only if `status` is `approved`. No invented events: a pin is added only once its organiser has confirmed it. Every property is plain text.

| Property | Meaning |
|---|---|
| `id` | short unique name |
| `kind` | `happening`, `learning-journey`, `partner-event` or `example-place` |
| `title` | shown in the popup and as the map label |
| `summary` | plain text, 300 characters or fewer |
| `date` | text, optional |
| `place_name` | text, optional |
| `url`, `url_label` | an https link and its text (the organiser's own page for partner events) |
| `source_url` | an https link to the source of the facts |
| `status` | `draft` or `approved` |

The geometry is a `Point` with `[longitude, latitude]`. For events at private homes use a public place or round to about 100 m. Do not add private addresses or named private individuals without their consent. The popup tag and the empty-state text follow `kind`, so adding a real event needs no code change. The Layers panel label still reads "Example place" and counts every pin, so rename it when real events go in. While no real pins exist, the Layers panel says "No events listed yet."

If pins later come from a Google Sheet, publish only a separate tab that holds approved rows. "Publish to the web" exposes every row of the published tab, so a status column alone does not keep drafts private. CORS on a published sheet has not been tested.

## Checks

```sh
node scripts/check-demo.mjs            # static checks, plain Node, no dependencies
node scripts/check-demo.mjs --browser  # also runs the headless browser checks
```

[scripts/check-demo.mjs](scripts/check-demo.mjs) first proves each "must not contain" rule can fire, by running it on seeded bad input, then checks this folder: no held-layer file names (native-land, rush, hydro, person), no email addresses, phone numbers, tokens or private path markers in the page, data, README and fetch script (not in LICENSE, the other scripts or the git history), every URL on an allowed host, no root-relative paths, pin rules (status, kind, https links), a size limit of 10 MB, every layer file present with valid GeoJSON inside the demo box, the licence statement, banner and credits present, and the vendored MapLibre files matching their pinned checksums. It also checks that LICENSE is the MIT text, that the README says MIT covers the code only, that the park layer has no Capital Regional District rows, that the credits carry each kept provider's statement (Victoria, Saanich, Islands Trust) and the terrain lines word for word, and that the flow lines point downstream. The direction rule runs at two creek mouths, the Colquitz River at Portage Inlet and Bowker Creek at the Oak Bay shore, and its self-test feeds it reversed lines and a missing creek. A second self-test runs `scripts/make-flow.mjs` on a creek drawn the right way (it turns it around) and on one already drawn downstream (it refuses). For the new layers it checks that the flow file includes the canals and not the pipes (Bowker Creek open channel between 1,300 and 1,600 m, with self-tests for canals missing and pipes included), that every new layer has a box and all are off, including 3D terrain, that the Live data sentence is present, that Environment and Climate Change Canada data is never credited to the Open Government Licence, that the privacy note names every host the page fetches from after a box is ticked, that the credits carry the Environment Canada, USGS, ecoregion and industry source statements word for word, and that the industry file holds only the open sources, only the kinds shown and no site named for a First Nation. It then runs `js/overlays-data.js` on sample replies: radar frame times are read from the radar layer and not a sibling, an expired alert is dropped and an alert text passes unchanged, the AQHI band is read on the rounded index, only earthquakes inside the area are kept, conditions keep the newest report per station, gauges are sorted nearest first and a station number is checked before it goes into a URL, and GBIF records under another licence, withheld, generalised, too uncertain, outside the box or repeated are dropped while positions are rounded to 0.01 degree.

[scripts/browser-check.mjs](scripts/browser-check.mjs) loads the page in headless Chromium at 1280 px and 390 px wide. It needs Playwright, which is not a dependency of this folder: set `PLAYWRIGHT_MODULE` to an existing install, or leave it unset if `playwright` resolves from here. It also needs network access for the basemap, the elevation tiles and, on the desktop run, each live service. It checks for page errors, horizontal overflow, layer toggles, the example popup, the municipality popup, the credits panel, the Fit button, and the page with the basemap blocked. For the flow and terrain layers it checks that Flow is on by default and its loop stops when the Flow or creeks box is off, when the tab is hidden and (on a phone) when zoomed out, that the dash pattern marches along vertex order on all 14 steps (a west to east test line is drawn and its pixels compared step by step), that under reduced motion Flow is off, disabled and never animates and follows the setting live, that on load the page contacts only the basemap host and the elevation tiles, and that Terrain shading is on at load with its credit and can be switched off and on. For 3D terrain it checks that the map is tilted to 60 degrees with terrain, sky and rotation at load (already tilted under reduced motion), and, after switching it off for the other checks, that ticking the box sets terrain from the elevation tiles, tilts to 60 degrees, unlocks rotation, adds a sky, requests elevation tiles, shows the terrain credit with shading off, leaves the Terrain shading box alone (and the reverse), still draws and can query the creeks, lakes, parks and boundaries over the relief, and that unticking it takes pitch and bearing back to 0 and removes the terrain. For the new layers it checks, on the desktop run and against the real services, that nothing is requested from Environment Canada, USGS or GBIF (or for the two data files) until a box is ticked, that ticking each box contacts its own host and no other, shows its layer, a status line and its credit on the map, that the radar has several frames, plays, pauses and fetches its colour key only when opened, that the life observation and industry popups are built from text only and carry their licence, basis and source links, that a click on an industry site opens its popup, and that unticking everything hides the layers, the status lines and the credits. A separate run blocks all four outside hosts and checks that each live box makes its own request and then shows a plain failure line, that the layer stays empty, that nothing throws, that a made-up alert is shown word for word, and that the two static layers still load. The page is declared ready by a `window.__ready` flag in test mode, because the map's own `loaded()` and `idle` do not settle while the dashes animate.

Not tested yet: the deployed site on a phone and a desktop (see the post-deploy checks under Hosting), Safari, Firefox, a screen reader, keyboard-only use of popups (popups open from mouse or touch only), a Sheet-fed pins layer, and the look of the flow animation in motion (its direction is checked by pixel comparison, but its speed and dash size were set from still screenshots, not watched). Also not tested: how fast 3D terrain runs on a real phone, which matters more now that it is on by default. The headless browser draws in software on a loaded machine and managed one to three frames a second at 390 px wide, 2D and 3D alike, so its numbers say nothing about a phone. The 3D view was about two to three times slower than 2D there. The Flow animation is halved in 3D as a precaution, and the layer can be dropped from a build if a phone struggles. Also not tested: the live layers on a phone, how the radar looks in steady rain (it was nearly dry on the test day, with only a light patch east of the San Juan Islands), and a weather alert from the real service (none was in effect, so the alert path was run on a made-up alert).

## Refreshing the data

[scripts/fetch-layers.sh](scripts/fetch-layers.sh) downloads the layers from the BC Data Catalogue WFS and rebuilds `data/*.geojson` with mapshaper 0.7.93 and, for the flow lines, [scripts/make-flow.mjs](scripts/make-flow.mjs) (plain Node). Run it on a developer machine, never from the browser, then run the checks and commit. Set `FETCH=0` to reprocess already-downloaded files in `raw/` (which is not committed). On 2026-10-21 the whole script, download step included, was run from scratch. It reproduced seven of the committed layers byte for byte, changed `greenspaces.geojson` (Capital Regional District rows removed) and created `streams-flow.geojson`. The Islands Trust row was filtered out of the committed file for a time and put back on 2026-10-21 from the earlier local build of the file. Because the simplifier ranks vertices across the whole layer, a full run can differ from the committed `greenspaces.geojson` by a few vertices in that row and in other parks.

[scripts/make-industry.mjs](scripts/make-industry.mjs) builds `data/industry-waste.geojson` from the Salish Sea Atlas snapshot `material-sites-salish.json` (pass its path as the first argument). It keeps sites inside the box from the three open sources, drops every other source's records, the river-plastic kind and the site named for a First Nation, and keeps each figure's basis in words. `data/ecoregions.geojson` was made once, from the Atlas's `ecoregions-2017.pmtiles` (`pmtiles extract` for the box, then the z8 tile decoded to GeoJSON and clipped with mapshaper 0.7.93), and checked against the RESOLVE UTFGrid tiles at four points. The steps are in [data/SOURCES.md](data/SOURCES.md).

## Hosting

The site is served by GitHub Pages, deployed from the `main` branch, root folder, at https://darrenzal.github.io/greater-victoria-map/. It is plain static files, so there is no build step. Every path in the page is relative, so it works under the project path. `.nojekyll` stops GitHub from running Jekyll over the files.

After each deploy:

1. Run `curl -sI -H 'Accept-Encoding: gzip'` on the three `.mjs` files under `vendor/` (`maplibre-gl.mjs`, `maplibre-gl-shared.mjs`, `maplibre-gl-worker.mjs`) and expect `content-type: text/javascript` and `content-encoding: gzip`. If `.mjs` were served with the wrong type, load MapLibre from the jsDelivr copy of 6.9.0 instead.
2. Open the page on a phone and a desktop, confirm the demo banner and attribution show, and open the example popup.

The repository is public, so its history is public too. Before pushing, run both checks and scan the repository for personal paths, email addresses and tokens. Updates: edit pins in the repository, or refresh the provincial data with the fetch script.

Visitor privacy: the page uses no analytics and no cookies. Map tiles come from tiles.openfreemap.org, so that service receives visitors' tile requests. Terrain shading and 3D terrain are on by default, so elevation tiles come from s3.amazonaws.com on every visit until a visitor switches both off, and Amazon Web Services receives those requests too. The credits say so. If a visitor ticks a live layer, their browser, with its internet address, contacts the service behind it: Environment and Climate Change Canada (api.weather.gc.ca for alerts, air quality, conditions and gauges, geo.weather.gc.ca for radar), the U.S. Geological Survey (earthquake.usgs.gov) or GBIF (api.gbif.org). The privacy note in the credits names each of these hosts. All of them answer browsers directly (Access-Control-Allow-Origin: *, checked with curl and an Origin header on 2026-10-21, and by the requests the browser check makes from a page on another origin), so no proxy or key is needed. The tile notes say the elevation bucket is meant for efficient use from EC2 and is not behind a CDN, so a busy public site should host pre-extracted tiles instead. That matters more now that terrain is on by default. A self-hosted Protomaps extract of the Greater Victoria area (about 3.6 MB at zoom 13) would remove that third-party request, but needs hosted fonts and sprites and is about a day of work.

Risks: OpenFreeMap is a single-operator service with no SLA and can change or stop without notice, the boundaries are provincial and approximate, and a public repository makes the data files and the pins history public. The live layers add more of the same: each depends on a service that can change or stop, GBIF refuses a burst of requests (the loader asks one at a time and reports a partial result), and a busy public site would send many visitors' requests straight to Environment Canada, the USGS and GBIF. Their terms for that were not read beyond the licences quoted in [data/SOURCES.md](data/SOURCES.md), and GBIF's own terms page could not be fetched from the live site (see open item A6).

## Open items

- **A1.** Park licences were read on 2026-10-21 (see [data/SOURCES.md](data/SOURCES.md)). Victoria, Saanich and Islands Trust are kept with their statements. One provider is removed from the map.
  - Capital Regional District. The only terms found forbid passing its data on and name no open licence, so 75 rows (27 regional parks such as Thetis Lake, Elk/Beaver Lake and East Sooke, plus parks of Metchosin and Highlands) are off the map until the CRD confirms an open licence in writing. To restore them, remove `lic!="C"` from the filter in [scripts/fetch-layers.sh](scripts/fetch-layers.sh), run the script, and add the statement the CRD specifies to the credits, the park popups and the checks.
  - 532 rows have no provider statement and rest on the Province's OGL-BC licence alone. Either read each municipality's terms or ship only rows with an explicit statement (402 rows).
- **A2.** Whether and how to show First Nations territories is open, including consulting the Nations (Lekwungen, W̱SÁNEĆ communities) first. The credits make no statement about territories. Native Land needs Native Land Digital's written permission before it is used in any form: its Data Sovereignty Treaty prohibits storing or distributing API data without permission, and its API key cannot be kept secret in a static page. The other sources found in the 2026-10-21 licence read are below. None is on the map, and each should be re-read before anyone relies on it.
  - Native Land Digital (territories, languages, treaties, by API): written permission from Native Land Digital, via https://native-land.ca/contact. Its pages say the data is for non-commercial and educational use, with attribution and acknowledgement of Indigenous communities as stewards. Its "What We Map" page says territories will no longer be provided through the API (undated), so languages is the likelier layer.
  - First Peoples' Map of B.C. (First Peoples' Cultural Council), https://maps.fpcc.ca/page/tos: language regions, place names and band offices. The terms are copyright with no open licence and forbid copying, merging or publishing the data. An iframe embed with acknowledgement is allowed, and API use needs approval from the Council. Language regions are not territory.
  - Reserves (Aboriginal Lands of Canada Legislative Boundaries, Natural Resources Canada, https://open.canada.ca/data/en/dataset/522b07b9-78e2-4819-b736-ad9208eb1067): Open Government Licence - Canada, usable with attribution. Legal reserve parcels under Indian Act names, not traditional territory, so how they are labelled is a Nation-relations question.
  - First Nations Location (Indigenous Services Canada points, https://open.canada.ca/data/en/dataset/b6567c5c-8339-4055-99fa-63f92114d9e4): Open Government Licence - Canada. Administrative office locations, not territory.
  - Historic Treaties (Crown-Indigenous Relations, https://open.canada.ca/data/en/dataset/f281b150-0645-48e4-9c30-01f55f93f78e): Open Government Licence - Canada. One island-wide Douglas Treaties estimate for Victoria, "for informational and representational purposes only".
  - BC Data Catalogue First Nations layers (treaty areas and lands, community locations) and BC Geographical Names with the Indigenous tag: "Access Only", so written permission from the Province is needed (its Copyright Permission Request Form).
  - Nation-published material (the W̱SÁNEĆ Leadership Council's SENĆOŦEN place names map, the Songhees, Esquimalt, T'Sou-ke and Scia'new websites, the Te'mexw Treaty Association statement of intent map): no reuse terms found, so each needs the Nation's or the body's permission. The treaty-association map shows preliminary negotiation boundaries from the early 2000s.
- **A3.** RUSH. Nothing about RUSH is included unless RUSH agrees.
- **A4.** Environment and Climate Change Canada licence. The live layers use the End-use Licence read on 2026-10-21 (version 2.1.1, August 2026). The Salish Sea Atlas credits the same radar to the Open Government Licence – Canada, which the licence page does not say. Before the page goes public, decide whether to keep the statement the licence prescribes when a service names none, and re-read the licence for any change (its section 9 says the version in force when the data was accessed governs). Stations run by other bodies (NAV CANADA, PC-NRMB, and the B.C. Ministry of Environment for one gauge) are named in popups as the licence asks, and the Parks Canada code PC-NRMB is shown as published, not expanded.
- **A5.** Ecoregions and industry sites. The ecoregion polygon is a generalised copy (z8 tiles of the Atlas), not the 150 MB official shapefile, and the shape of the coast comes out coarse. Statistics Canada's Open Database of Infrastructure landing page (https://www150.statcan.gc.ca/n1/pub/34-26-0003/342600032023001-eng.htm) was unavailable on 2026-10-21 (a maintenance page), so its wording rests on the Atlas's record of 2026-09-24, and the Open Government Licence – Canada text itself was read on 2026-10-21. Ten of the eleven landfill points are unnamed "Facility mixed" locations. The wastewater site named for a First Nation is left out (see "Left out on purpose"). River-plastic outfalls could be added back as a separate, clearly modelled layer.
- **A6.** GBIF's data user agreement (https://www.gbif.org/terms/data-user) returned HTTP 403 to curl and to the browser tool on 2026-10-21 (Cloudflare), so it was read from the Internet Archive copy of 2025 (last updated 16 August 2017). It says users "must comply with the terms and conditions included in the licence selected by each Data Publisher", that "the identifier of ownership of data must be retained with every data record shared onward for reuse" and that "it is forbidden to use APIs to create denial of service". The layer keeps each record's dataset and licence, and asks for 300 records once per tick. Re-read the live page before launch.
- **Data edge.** The data layers end at the demo box. On a wide screen the home view shows the western edge of the data near Sooke (about 123.75 W), where layers stop and the basemap continues. A wider box costs file size.
- **Creek length.** The Freshwater Atlas has 12 named Bowker Creek segments, about 2.1 km of a creek the 2012 Blueprint measures at 9.4 km, because piped stretches are unnamed or unmapped. The popups say so.
- **Watershed sizes.** The Province draws the Bowker Creek watershed at 1,381 ha. Other sources use other figures. The watershed popup says other groups draw watersheds differently.
- **Dependency on a newer MapLibre.** MapLibre 6.9.0 is pinned because it is the version already in use and tested in the related [Salish Sea Atlas](https://salishsee.life) project. Later releases exist, and an upgrade is a later, deliberate step. Version 6.x has no UMD file, so the page loads MapLibre as an ES module.
